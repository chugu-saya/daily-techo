# デイリー手帳

紙の手帳のようなデイリーページを、オフラインで使えるアプリです。

- `app/` … PWA版（スマホ・PCにインストールできる）。GitHub Pages で公開されます
- `planner.html` … PCでダブルクリックして使う1ファイル版

## 更新のしかた
1. `app/index.html` を直す
2. `app/sw.js` の `VERSION` を1つ上げる（例：`'v1'` → `'v2'`）
3. コミットして `main` に push すると、自動で公開されます

## データの保存と同期
- 書いた内容は各端末のブラウザ内に保存されます。
- 「保存」メニューから同期を設定すると、PC・スマホ間でリアルタイムに同期します（Firebase）。
  内容はメールアドレスと合言葉から作った鍵で端末内で暗号化してから送るため、サーバー側では読めません。
  合言葉を忘れるとサーバー上のデータは復元できません。
- Firestore のアクセスルールは `firestore.rules`（Firebase コンソールの Firestore →「ルール」に貼り付けて公開）。
