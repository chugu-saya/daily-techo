# デイリー手帳

紙の手帳のようなデイリーページを、オフラインで使えるアプリです。

- `app/` … PWA版（スマホ・PCにインストールできる）。GitHub Pages で公開されます
- `planner.html` … PCでダブルクリックして使う1ファイル版

## 更新のしかた
1. `app/index.html` を直す
2. `app/sw.js` の `VERSION` を1つ上げる（例：`'v1'` → `'v2'`）
3. コミットして `main` に push すると、自動で公開されます

データは各端末のブラウザ内にだけ保存され、サーバーには送られません。
